# キーマップ早見表

`<leader>` = **Space**。迷ったら Space を押して少し待てば which-key がメニューを出してくれる。

---

## 自作キーマップ

| キー | 動作 |
|---|---|
| `Space w` | 保存 |
| `Space q` | 閉じる |
| `Space ?` | キーマップ一覧 |
| `Esc` | 検索ハイライトを消す |
| `Ctrl h/j/k/l` | ウィンドウ移動（ツリー ⇔ 編集画面 ⇔ ターミナル） |

### ファイル・検索（VS Code の Cmd+P / Cmd+Shift+F）
| キー | 動作 |
|---|---|
| `Space e` | ファイルツリー開閉 |
| `Space Space` | ファイルを開く（あいまい検索） |
| `Space f f` | ファイル名で検索 |
| `Space f g` | 全文検索 |
| `Space f r` | 最近開いたファイル |
| `Space f b` | 開いているファイル一覧 |

ファイルツリー内: `Enter` 開く / `a` 新規作成（末尾 `/` でフォルダ）/ `d` 削除 / `r` 名前変更 / `?` ヘルプ  
検索画面内: 文字を打って絞り込み → `Enter` で開く / `Esc` で閉じる

### ターミナル（VS Code の Ctrl+`）
| キー | 動作 |
|---|---|
| `Ctrl /` または `Space t` | 下にターミナル開閉 |
| `Space T` | フローティングターミナル |
| `Esc` 2 回 | ターミナル内でスクロール・コピーできるモードへ |

### Git / GitHub（VS Code のソース管理）
| キー | 動作 |
|---|---|
| `Space g g` | Lazygit（ステージ・コミット・プッシュなど全部ここで） |
| `Space g e` | 変更ファイルをツリー表示 |
| `Space g s` | 変更ファイルを検索 |
| `Space g l` | このファイルのコミット履歴 |
| `] h` / `[ h` | 次 / 前の変更箇所へ |
| `Space g h` | 変更内容をプレビュー |
| `Space g a` / `Space g r` | この変更をステージ / 取り消す |
| `Space g b` | この行を誰がいつ変えたか |
| `Space g d` | 差分を左右に表示 |
| `Space g o` | 今の行を GitHub のページで開く |
| `Space g i` | Issue 一覧 |
| `Space g p` | Pull Request 一覧（`Enter` でコメント・マージなどの操作） |

Lazygit 内: `Space` ステージ / `c` コミット / `P` プッシュ / `p` プル / `?` ヘルプ / `q` 閉じる

## Vim の基本（まずはこれだけ）

### モード
| キー | 動作 |
|---|---|
| `i` / `a` | カーソルの前 / 後から入力 |
| `o` / `O` | 下 / 上に行を作って入力 |
| `v` / `V` | 文字 / 行選択 |
| `Esc` | Normal モードに戻る |

### 移動
| キー | 動作 |
|---|---|
| `h j k l` | ← ↓ ↑ → |
| `w` / `b` | 次 / 前の単語へ |
| `0` / `$` | 行頭 / 行末 |
| `gg` / `G` | ファイル先頭 / 末尾 |
| `5j` | 5 行下へ（相対行番号の数字を見て使う） |
| `Ctrl d` / `Ctrl u` | 半画面下 / 上 |

### 編集
| キー | 動作 |
|---|---|
| `x` | 1 文字削除 |
| `dd` / `yy` / `p` | 行削除 / 行コピー / 貼り付け |
| `u` / `Ctrl r` | 元に戻す / やり直す |
| `.` | 直前の編集を繰り返す |
| `ciw` | 単語を書き換え（change inner word） |

### 検索・置換
| キー | 動作 |
|---|---|
| `/文字列` | 検索（`n` / `N` で次 / 前） |
| `*` | カーソル下の単語を検索 |
| `:%s/old/new/g` | ファイル全体で置換 |

### 保存・終了
| キー | 動作 |
|---|---|
| `:w` | 保存 |
| `:q` | 閉じる |
| `:q!` | 保存せず閉じる |
