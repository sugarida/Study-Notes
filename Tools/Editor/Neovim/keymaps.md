# キーマップ早見表

`<leader>` = **Space**。迷ったら Space を押して少し待てば which-key がメニューを出してくれる。

---

## 自作キーマップ

| キー | 動作 |
|---|---|
| `Space w` | 保存 |
| `Space q` | 閉じる |
| `Space ?` | キーマップ一覧 |
| `Esc` | 検索ハイライトを消す |
| `Ctrl h/j/k/l` | ウィンドウ移動 |

---

## Vim の基本（まずはこれだけ）

### モード
| キー | 動作 |
|---|---|
| `i` / `a` | カーソルの前 / 後から入力 |
| `o` / `O` | 下 / 上に行を作って入力 |
| `v` / `V` | 文字 / 行選択 |
| `Esc` | Normal モードに戻る |

### 移動
| キー | 動作 |
|---|---|
| `h j k l` | ← ↓ ↑ → |
| `w` / `b` | 次 / 前の単語へ |
| `0` / `$` | 行頭 / 行末 |
| `gg` / `G` | ファイル先頭 / 末尾 |
| `5j` | 5 行下へ（相対行番号の数字を見て使う） |
| `Ctrl d` / `Ctrl u` | 半画面下 / 上 |

### 編集
| キー | 動作 |
|---|---|
| `x` | 1 文字削除 |
| `dd` / `yy` / `p` | 行削除 / 行コピー / 貼り付け |
| `u` / `Ctrl r` | 元に戻す / やり直す |
| `.` | 直前の編集を繰り返す |
| `ciw` | 単語を書き換え（change inner word） |

### 検索・置換
| キー | 動作 |
|---|---|
| `/文字列` | 検索（`n` / `N` で次 / 前） |
| `*` | カーソル下の単語を検索 |
| `:%s/old/new/g` | ファイル全体で置換 |

### 保存・終了
| キー | 動作 |
|---|---|
| `:w` | 保存 |
| `:q` | 閉じる |
| `:q!` | 保存せず閉じる |
