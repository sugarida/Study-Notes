# 使用プラグイン一覧

## ファイル管理
- nvim-tree.lua  
  → Explorer 相当のファイラー

## Git
- gitsigns.nvim  
  → 行単位の差分表示
- vim-fugitive  
  → Git 操作の中核
- neogit  
  → VS Code ライクな Git UI

## GitHub
- octo.nvim  
  → PR / Issue 操作（gh CLI 連携）

## IDE
- nvim-lspconfig  
  → LSP 設定
- mason.nvim  
  → LSP 管理

## 補完
- nvim-cmp  
  → オートコンプリート

## 検索
- telescope.nvim  
  → ファイル検索・全文検索
