# Neovim セットアップ手順（Windows）

## 前提環境
- OS: Windows
- ターミナル: PowerShell / Windows Terminal

---

## 1. 必須ツール

- Neovim (v0.9+)
- Git for Windows
- GitHub CLI (`gh`)
- Nerd Font（JetBrainsMono / FiraCode など）

---

## 2. Git / GitHub CLI

```powershell
git --version
gh --version


## 3. Github 認証(一回だけ)
gh auth login
``
