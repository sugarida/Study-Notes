### OSI参照モデル
通信を7層に分けて定義したモデル

### TCP/IPモデル
実通信に使われる4層モデル

* ###### 物理層(L1)
  * ビット伝送を担当
  * 例：ケーブル，NIC，ハブ
* ###### データリンク層(L2)
  * フレーム転送・MACアドレス制御
  * 例：スイッチ，ブリッジ
* ###### ネットワーク層(L3)
  * パケット転送と経路制御
  * 例：ルーター
* ###### トランスポート層(L4)
  * 通信の信頼性確保
  * 例：TCP/UDP
* ###### アプリケーション層(L7)
  * サービス提供層
  * 例：HTTP，DNS，SMTP

### MACアドレス
L2での識別用アドレス
48bit，16進数,NIC固有
OUI+デバイス識別部 (24bit+24bit)
### IPアドレス
L3での識別用アドレス
IPv4=32bit,IPv6=128bit
### サブネットマスク
ネットワーク部/ホスト部を区別
255.255.255.0 = /24
### デフォルトゲートウェイ
異ネットワーク転送時の出口
ルータのIPアドレスを指定


### ARP
IP⇔MAC変換 IPv4でのアドレス解決
`arp -a`

### ICMP
通信確認プロトコル
`ping`,`traceroute`

### DNS
名前解決サービス
UDP/TCP 53番
* Aレコード ： ホスト名を直接IPアドレスに関連付ける
```
 NAME CLASS RDATA
 example.com. IN A 192.0.2.1  
```

* CNAMEレコード ： ホスト名を別のホスト名に関連付ける(エイリアスを提供)
```
NAME CLASS RDATA
www.example.com. IN CNAME example.com
```

### DHCP
動的IP割当サービス
DORAプロセス
Discover→Offer→Request→Ack

### NAT
プライベートIP⇔グローバルIP変換
静的NAT，PAT等
`show ip nat translantions`

### PAT
ポート番号で識別するNAT
NAT Overloadとも呼ばれる
